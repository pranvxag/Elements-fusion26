# AgriRisk Intelligence

A Next.js application for climate-aware agricultural lending decision support.

## Run locally

### Prerequisites

- Node.js 20 or newer
- pnpm 12 or newer

Check the installed versions:

```bash
node --version
pnpm --version
```

### Install dependencies

From the project root, run:

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server reloads automatically when source files change. Stop it
with `Ctrl+C`.

## Production build

To check and run an optimized production build locally:

```bash
pnpm build
pnpm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Available commands

| Command | Purpose |
| --- | --- |
| `pnpm install` | Install project dependencies |
| `pnpm dev` | Start the development server |
| `pnpm build` | Create an optimized production build |
| `pnpm start` | Serve the production build |
